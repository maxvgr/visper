# Backend integration

## Формы

Frontend отвечает за:

- маски полей;
- визуальную валидацию;
- обязательное согласие на обработку персональных данных;
- отображение ошибок;
- отображение модальных окон.

В production frontend не перехватывает успешную отправку формы.

Backend может использовать обычную отправку формы или собственный AJAX.

После успешной AJAX-отправки формы вызвать событие:

```js
window.dispatchEvent(new CustomEvent("formSuccess", {
  detail: { form },
}));
